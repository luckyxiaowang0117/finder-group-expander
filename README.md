# Finder 分组自动展开

一个 macOS 菜单栏小工具：访达（Finder）打开硬盘窗口（图标视图 + 按种类分组）时，
自动点开每个分组右上角的「全部显示」按钮，免得每次手动一个个点。

只用 macOS 辅助功能 API（AXPress）操作，全程后台运行，不动鼠标、不抢焦点。

## 功能

- **自动扫描硬盘**：启动时枚举本机所有已挂载的硬盘（启动盘、外置硬盘、U盘），
  设置里逐个勾选对哪些盘生效；新插入的硬盘默认自动启用。
- **适用范围**：已启用硬盘上的任意访达窗口（根目录和子文件夹都行），
  只有窗口里出现「全部显示」按钮时才动手，没有就不动。
- **时间设置**：打开窗口后延迟多久开始展开、每展开一组间隔多久、
  一轮最多点几次、没展开完时多久后再补扫，都可以在设置里调。
- **菜单栏常驻**：菜单栏小图标，点开可以开关总功能、打开设置、退出。
- **开机自启**：设置里可开关（macOS 13+ 的 SMAppService）。
- **运行日志**：写到 `~/Library/Logs/FinderGroupExpander.log`，可在设置里开关和打开查看。

## 系统要求

- macOS 13.0 或更高（Apple Silicon / Intel 都行）
- 需要给 App 开「辅助功能」权限（下面“首次运行”有说明）
- 打包需要 Xcode Command Line Tools（`xcode-select --install`）和 Swift 5.9+

## 打包（给 Codex / 手动执行）

```bash
cd FinderGroupExpander
bash build-app.sh
```

脚本会做三件事：`swift build -c release` 编译、组装出 `FinderGroupExpander.app`、
ad-hoc 签名（仅本机运行可用）。完成后把 `.app` 拖进「应用程序」文件夹即可。

也可以直接用 Xcode 打开：`swift package generate-xcodeproj` 已废弃，
建议就用上面的脚本，或在 Xcode 里新建 App 工程、把 `Sources/FinderGroupExpander`
下的源码加进去。

## 首次运行

1. 把 `FinderGroupExpander.app` 拖进「应用程序」。
2. **右键 → 打开**（第一次这样开一次，绕过 Gatekeeper 对未签名 App 的拦截；
   打包时如果用自己的开发者证书签过名，这一步可以跳过）。
3. 打开后它会提示要辅助功能权限：去「系统设置 → 隐私与安全性 → 辅助功能」，
   把 FinderGroupExpander 的开关打开；或者在 App 自己的设置窗口里点「打开系统设置」。
4. 第一次启动会自动打开设置窗口，主人在「适用硬盘」里确认要生效的硬盘，
   其他时间参数一般不用改。

## 设置说明

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用自动展开 | 开 | 总开关，关掉后什么都不做 |
| 适用硬盘 | 全部启用 | 逐个勾选，插拔后列表自动刷新；优先按卷 UUID 保存设置，卷没有 UUID 时按挂载路径保存 |
| 打开窗口后延迟 | 0.2 秒 | 等窗口内容加载完再开始 |
| 每展开一组间隔 | 0.2 秒 | 点完一组隔多久点下一组 |
| 没展开完多久后补扫 | 0.8 秒 | 一轮没点完，隔多久再试 |
| 一轮最多点几次 | 10 次 | 防止异常情况下一直点 |
| 开机自动启动 | 关 | 下次开机自动运行 |
| 显示菜单栏图标 | 开 | 关掉后只能在设置里操作 |
| 记录运行日志 | 开 | `~/Library/Logs/FinderGroupExpander.log` |

## 已知限制

- 只对「图标视图 + 按种类分组」下出现的「全部显示」按钮生效；如果访达没开分组，
  本来就没有这个按钮，App 也就什么都不做。
- 判断窗口属于哪块硬盘主要靠窗口的 AXDocument（当前文件夹路径）。
  需要用窗口标题识别硬盘时，只有标题唯一匹配一个已挂载卷才会展开。
- 触发方式是每 0.5 秒巡查一次访达窗口（不是逐窗口事件监听），
  目的是兼容各版本系统；巡查本身很轻量。
- 未做代码签名分发，换电脑需要重新打包/授权；辅助功能权限每台电脑都要单独开一次。

## 来源

核心逻辑先用 Hammerspoon 原型（`init.lua` v6）在 macOS 27.2.1 + gutai 外置盘上验证通过：
「全部显示」在无障碍树里是 `AXButton`，标题形如「全部显示(30)」；
AXPress 可以点开它；中文系统里访达的应用名是「访达」（不是 "Finder"），
所以判断是不是访达窗口要用包名 `com.apple.finder`。
这个 App 就是把同一套逻辑做成了独立应用。

## 卸载

退出 App（菜单栏图标 → 退出），把 `FinderGroupExpander.app` 拖进废纸篓；
设置保存在用户偏好里，不用手动清理。
